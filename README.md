# wechat-
# 微信健康追踪小程序 

项目概述

本项目是一款基于微信小程序的健康追踪应用，集成饮食记录、运动管理、体重监测、饮水追踪、睡眠记录等核心功能。

## 技术栈

### 前端框架
- **微信小程序框架**：原生开发，支持多平台
- **WXML**：页面结构
- **WXSS**：样式设计（类CSS语法）
- **JavaScript**：业务逻辑处理

### 后端服务
- **腾讯云开发CloudBase**：提供云函数和数据库支持
- **云开发数据库**：NoSQL数据库存储用户数据

### 开发工具
- **微信开发者工具**：小程序开发和调试

## 功能模块

### 1. 首页模块
- 今日健康数据总览（热量、步数、体重、饮水、睡眠）
- 快速操作入口
- 今日饮食记录预览
- 运动记录入口

### 2. 饮食管理
- 快速添加食物（预设11种常见食物）
- 自定义添加食物（支持保存到快速添加列表）
- 删除自定义食物
- 按餐食分类（早餐、午餐、晚餐、加餐）
- 热量统计

### 3. 体重监测
- 每日体重记录
- 体重变化趋势
- 目标体重设置
- 历史体重查询

### 4. 饮水追踪
- 快速记录饮水量
- 每日饮水目标设置
- 饮水历史查询

### 5. 睡眠记录
- 睡眠时长记录
- 睡眠质量追踪
- 每日睡眠目标

### 6. 步数管理
- 步数数据记录
- 步数目标设置
- 历史步数查询

### 7. 运动管理
- 多种运动类型（跑步、骑行、健走、徒步）
- 自定义添加运动类型
- 运动卡路里计算
- 运动记录统计

### 8. 个人中心
- 用户头像自定义（18种表情头像可选）
- 用户昵称自定义
- 健康目标设置（热量、体重、饮水、睡眠）
- 身体数据设置（身高、年龄）

## 数据存储

### 本地存储
- `user_profile`：用户基本信息（昵称、头像、健康目标、身体数据）
- `diet_records`：饮食记录
- `weight_records`：体重记录
- `water_records`：饮水记录
- `sleep_records`：睡眠记录
- `step_records`：步数记录
- `sport_records`：运动记录
- `user_custom_foods`：用户自定义食物

### 云端存储
- 用户数据备份
- 云函数处理复杂业务逻辑
